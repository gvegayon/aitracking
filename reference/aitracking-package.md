# aitracking: Measure the Effects of AI Coding Using the GitHub API

A lightweight pipeline to measure the effects of AI-assisted coding on
software projects using the GitHub REST API. Retrieves commit histories
(including lines added and deleted), issue and pull request activity,
download and clone statistics, and the evolution of a project's size in
lines of code by language. Provides a parsimonious, rule-based
classifier to flag commits and interactions in which AI coding agents
were involved, and base-graphics visualizations of project activity over
time. API access is implemented with base R connections to keep
dependencies to a minimum.
